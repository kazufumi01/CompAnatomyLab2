Compressor Anatomy Lab 2 (Beta) — Windows Manual Installation
by Johan Plus Kei

! Note: This Windows build has NOT been tested on a real Windows machine.
  Please report problems via GitHub Issues.

[English]
Requires Windows 10 / 11 (64-bit)

1. Before extracting, right-click the zip › Properties › tick "Unblock" › OK.
2. Copy the whole "Compressor Anatomy Lab 2.vst3" folder to:
   C:\Program Files\Common Files\VST3
3. For standalone use, put "Compressor Anatomy Lab 2.exe" anywhere and run it.
4. Rescan plug-ins in your DAW.

Uninstall: delete "Compressor Anatomy Lab 2.vst3" from the folder above.
An .exe installer is also available on the Releases page
("Windows protected your PC" -> More info -> Run anyway).

[日本語]
この Windows 版は、実機での動作確認ができていません（自動ビルドで作成）。
動作しない・不安定な場合があります。不具合は GitHub の Issues でお知らせください。
対応：Windows 10 / 11（64bit）

1. zip を展開する前に、zip を右クリック › プロパティ › 「許可する」にチェック › OK。
2. 展開した「Compressor Anatomy Lab 2.vst3」フォルダを丸ごと次へコピー（管理者の確認が出たら「続行」）：
   C:\Program Files\Common Files\VST3
3. 単体で使う場合は「Compressor Anatomy Lab 2.exe」を好きな場所に置いて起動。
4. DAW でプラグインを再スキャン。
   Live は「設定 › プラグイン」で「VST3 プラグイン システムフォルダ」をオン › 再スキャン。

アンインストール：上記フォルダから「Compressor Anatomy Lab 2.vst3」を削除。
手動が面倒な場合は Releases ページの .exe インストーラー版も使えます
（「Windows によって PC が保護されました」→「詳細情報」→「実行」）。
